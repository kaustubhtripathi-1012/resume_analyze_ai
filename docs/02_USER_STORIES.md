# User Stories
Format: As a [user], I want [action] so that [benefit].

- [ ] Story 1: As a candidate, I want to upload my resume so that I can see my extracted skills and experience.
  - Acceptance criteria: PDF/DOCX <= 5 MB accepted; parsed fields shown within 10 s; invalid files show clear error.
- [ ] Story 2: As a candidate, I want an ATS score so that I know how to improve my resume.
  - Acceptance criteria: Score 0-100 with at least 5 category scores and 3+ actionable suggestions.
- [ ] Story 3: As a candidate, I want to compare my resume with a job description so that I can see missing skills.
  - Acceptance criteria: Match % shown; matching and missing skills listed separately.
- [ ] Story 4: As a candidate, I want job recommendations so that I can apply to suitable roles.
  - Acceptance criteria: Top 5-10 jobs sorted by match %, each with a short reason.
- [ ] Story 5: As a recruiter, I want to post a job so that candidates can be matched to it.
  - Acceptance criteria: Title, description, skills, location required; job appears in listings.
- [ ] Story 6: As a recruiter, I want ranked candidates for my job so that I can shortlist faster.
  - Acceptance criteria: Candidates sorted by match %, only those who opted in to be visible.
- [ ] Story 7: As a candidate, I want to download my report so that I can keep or share it.
  - Acceptance criteria: PDF contains scores, skills, suggestions and date.
- [ ] Story 8: As an admin, I want to manage users and the skills taxonomy so that the system stays accurate.
  - Acceptance criteria: Admin can deactivate users and add/edit/merge skills; changes audited.
